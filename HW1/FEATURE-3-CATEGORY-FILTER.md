# Feature 3: Filter Projects by Category

- Add a dropdown with “All projects,” “Games,” and “Websites.”
- Give each project card a category.
- Selecting a category shows only matching cards; “All projects” shows both.
- Update a message such as “Showing 1 website project.”
- JavaScript listens for the dropdown’s `change` event, updates card visibility, and changes the message.

We’ll work through this feature one step at a time. I’ll teach the concepts as we build and test it; once it works, we’ll move to the next feature and repeat until all five are complete.
