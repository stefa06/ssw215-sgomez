# Feature 1: Save Favorite Projects

- Add a heart button to each project card: “♡ Save project”.
- Clicking it changes the button to “♥ Saved” and changes its color; clicking again unsaves it.
- Show a message such as “1 project saved” or “No projects saved.”
- JavaScript listens for clicks and updates the button text, `aria-pressed`, saved count, and a CSS class on the card.

We’ll work through this feature one step at a time. I’ll teach the concepts as we build and test it; once it works, we’ll move to the next feature and repeat until all five are complete.
