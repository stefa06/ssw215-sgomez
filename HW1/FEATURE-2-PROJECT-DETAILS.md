# Feature 2: Show or Hide Project Details

- Add a “More details” button and a short, initially hidden description to each card.
- Clicking the button reveals or hides the description.
- Change the button label between “More details” and “Hide details.”
- JavaScript listens for clicks and updates the description visibility and the button’s `aria-expanded` state.

We’ll work through this feature one step at a time. I’ll teach the concepts as we build and test it; once it works, we’ll move to the next feature and repeat until all five are complete.
