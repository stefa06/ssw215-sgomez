# Feature 4: Search Projects

- Add a labeled search box, such as “Find a project.”
- Typing “game” shows the video-game card; typing “site” shows the website card.
- Show “No projects found—try another search” when nothing matches.
- Add a “Clear search” button. Keep it disabled when the search is empty; enable it while the user types. Clicking it clears the search and restores all cards.
- JavaScript listens for typing and clicks, then updates card visibility, the message, and the clear button’s disabled state.

We’ll work through this feature one step at a time. I’ll teach the concepts as we build and test it; once it works, we’ll move to the next feature and repeat until all five are complete.
